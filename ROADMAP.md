# PseudOS roadmap

## 0.1.x: prove the foundation

- Get the first GitHub Actions build through ISO assembly and every QEMU check.
- Fix any XFCE-specific problems found by the live-session, persistence, and installed-system tests.
- Test the ISO in a VM and then on a small set of non-critical machines.
- Confirm Wi-Fi, Bluetooth, audio, removable storage, suspend/resume, and printer support on physical hardware.

## 0.2.x: polish the desktop

- Finalize a consistent panel layout and application menu.
- Add a PseudOS welcome and system-information utility.
- Review the default applications against the ISO-size budget.
- Improve installer wording and first-boot setup.

## Later

- Offer optional creative, education, and advanced development application bundles.
- Investigate broader hardware and architecture support.
- Add a signed update/release process for installed systems.

A roadmap item is a goal, not a claim that the feature already works.
