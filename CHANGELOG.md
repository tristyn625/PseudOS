# Changelog

## 0.1.0

- Initial Ubuntu 26.04 LTS live-system specification.
- XFCE 4.20 desktop integration with LightDM, original PseudOS branding, and a small developer toolkit.
- NetworkManager, Wi-Fi, Bluetooth, PipeWire, removable storage, printer and scanner support, broad hardware firmware, and desktop utilities.
- Firefox, VLC, LibreOffice, and Thunderbird Flatpaks, GNOME Software Flatpak integration, and Synaptic.
- USB persistence and a QEMU virtual-disk installation test through the pinned live-ISO build engine.
